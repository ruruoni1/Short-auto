# 니혼줍줍 디자인 시스템

## 1. 브랜드 방향

제품 목표가 아직 확정되지 않았으므로 아래 테마는 **검토·편집 제품을 위한 가역적인 초기안**이다. 일본 콘텐츠를 다루는 서비스라는 이름의 맥락은 반영하되, 전통 장식이나 관광 홍보물 같은 인상을 피하고 작은 편집숍과 독립 잡지의 정돈된 감각을 빌린다.

- **핵심 인상:** 따뜻함, 발견의 즐거움, 정돈된 편집 감각
- **피해야 할 인상:** 과장된 전통 일본 장식, 네온 일색의 클리셰, 지나친 귀여움
- **디자인 원칙:** 종이 같은 바탕, 먹색에 가까운 본문, 제한된 주홍 포인트, 편집 도구에 필요한 높은 정보 밀도
- **모션 원칙:** 콘텐츠를 설명하거나 행동을 확인하는 움직임만 사용한다.

## 2. 컬러

| 역할 | 토큰 | 값 | 용도 |
| --- | --- | --- | --- |
| Canvas | `--color-canvas` | `#F4F0E8` | 전체 배경 |
| Surface | `--color-surface` | `#FFFCF6` | 카드, 패널 |
| Surface muted | `--color-surface-muted` | `#EBE4D8` | 보조 영역 |
| Ink | `--color-ink` | `#24211D` | 본문, 제목 |
| Ink muted | `--color-ink-muted` | `#6F685F` | 설명, 메타 정보 |
| Border | `--color-border` | `#D7CFC1` | 구분선, 테두리 |
| Vermilion | `--color-accent` | `#D94A35` | 주요 CTA, 선택 상태 |
| Vermilion dark | `--color-accent-strong` | `#A93627` | hover/pressed |
| Indigo | `--color-indigo` | `#31465A` | 링크, 정보 강조 |
| Success | `--color-success` | `#3F7456` | 성공 상태 |
| Warning | `--color-warning` | `#A86E19` | 경고 상태 |
| Danger | `--color-danger` | `#B43B36` | 오류, 삭제 |

검토 상태는 색상만으로 표현하지 않는다.

| 상태 | 색상 역할 | 필수 동반 표현 |
| --- | --- | --- |
| 초안 | muted | `초안` 텍스트 + 문서 아이콘 |
| 검토 중 | indigo | `검토 중` 텍스트 + 말풍선 아이콘 |
| 변경 요청 | warning | `변경 요청` 텍스트 + 경고 아이콘 |
| 승인 완료 | success | `승인 완료` 텍스트 + 체크 아이콘 |
| 반려/검사 실패 | danger | 상태 텍스트 + 오류 아이콘 |

주홍색은 한 화면 면적의 약 10% 이내로 제한한다. 넓은 배경보다 버튼, 표시점, 밑줄 같은 작은 강조에 쓴다.

## 3. 타이포그래피

- **기본 글꼴:** `Pretendard Variable`, `Noto Sans KR`, `Noto Sans JP`, sans-serif
- **숫자/가격:** `font-variant-numeric: tabular-nums`
- **본문:** 16px / 1.7
- **보조문:** 14px / 1.55
- **화면 제목:** `clamp(2rem, 5vw, 4.5rem)` / 1.05 / -0.04em
- **섹션 제목:** `clamp(1.5rem, 3vw, 2.5rem)` / 1.15 / -0.025em
- **버튼:** 15px / 600

한국어와 일본어를 장식처럼 혼합하지 않는다. 일본어 표기가 정보로 필요할 때만 병기하고, 작은 크기의 일본어 한자를 과도하게 굵게 쓰지 않는다.

## 4. 공간과 형태

- 공간 단위: 4, 8, 12, 16, 24, 32, 48, 64, 96px
- 콘텐츠 최대 폭: 1200px
- 본문 읽기 폭: 720px
- 카드 모서리: 16px
- 작은 컨트롤 모서리: 10px
- 캡슐형 UI는 태그, 필터, 상태 표시처럼 의미가 있을 때만 사용
- 기본 그림자: 얇은 테두리 + 낮고 넓은 그림자. 떠 있는 카드처럼 과장하지 않음

## 5. 컴포넌트 규칙

### 버튼

- Primary: 진한 주홍(`--color-accent-strong`) 배경, 흰 글자, 최소 높이 44px
- Secondary: surface 배경, ink 글자, 1px border
- Tertiary: 배경 없이 텍스트/아이콘만
- hover는 2px 이내 상승, pressed는 원위치 및 0.99 scale
- focus-visible에는 3px 포커스 링을 항상 표시

### 카드

- 카드 전체가 클릭 가능하면 내부에 별도 중첩 링크를 두지 않는다.
- 이미지 비율은 목록에서 일관되게 유지한다: 기본 4:3, 세로 콘텐츠 3:4
- hover 시 테두리와 그림자만 미세하게 강화하고 텍스트 위치는 바꾸지 않는다.
- 카드 등장 순서는 읽는 방향대로 60ms 간격을 사용한다.

### 태그와 필터

- 태그는 정보, 필터는 동작이므로 시각적으로 구분한다.
- 선택된 필터는 색상 외에도 채워진 배경과 체크 표시로 상태를 전달한다.

### 이미지

- 실제 발견/장소/물건 이미지가 중심이다. 장식용 일러스트가 이미지를 압도하지 않는다.
- 이미지 위 텍스트는 가급적 피하고, 필요하면 하단 40%에 단색에 가까운 그라디언트를 둔다.
- 로딩 중에는 이미지 비율이 변하지 않는 skeleton을 사용한다.

### 검토·승인 화면

- 상단 상태 바와 하단 행동 바는 내용보다 앞에 튀지 않도록 surface/border 중심으로 표현한다.
- 우측 의견 패널의 너비 변화는 드래그 중 즉시 반영하고, 열기/닫기에만 짧은 transform을 사용한다.
- `필수 수정`, `제안`, `질문`, `참고`는 아이콘·라벨·색상을 함께 사용한다.
- 승인 버튼은 차단 조건이 0일 때만 primary가 된다. 차단 중에는 바로 위에 원인을 한 문장으로 표시한다.
- 버전 비교의 추가·삭제 표시는 배경색뿐 아니라 `+`, `−`와 텍스트 장식을 함께 사용한다.

### 타임라인

- 트랙 높이, 클립 위치, 재생 헤드처럼 정밀 조작 대상에는 장식 애니메이션을 적용하지 않는다.
- 드래그 중 클립은 포인터를 즉시 따라야 하며 transition을 끈다.
- drop 이후에만 160ms 이내의 위치 확정 피드백을 허용한다.
- 선택된 클립은 2px outline과 핸들로 표시하며 scale로 크기를 바꾸지 않는다.
- playhead는 시간 데이터에 직접 연결하고 CSS transition으로 뒤처지게 만들지 않는다.
- 오류가 있는 구간은 타임라인 마커와 검사 목록에서 같은 아이콘/라벨을 사용한다.

## 6. 모션 토큰

| 범주 | 시간 | 용도 |
| --- | --- | --- |
| Instant | 80ms | 눌림 피드백 |
| Fast | 160ms | hover, focus, 작은 아이콘 |
| Base | 240ms | 선택, 토글, 메뉴 |
| Slow | 420ms | 카드/섹션 등장 |
| Hero | 720ms | 첫 화면의 한 차례 핵심 등장 |

- Standard easing: `cubic-bezier(0.22, 1, 0.36, 1)`
- Emphasis easing: `cubic-bezier(0.16, 1, 0.3, 1)`
- Exit easing: `cubic-bezier(0.4, 0, 1, 1)`
- 기본 이동 거리: 12px, 큰 섹션: 최대 24px
- 기본 stagger: 60ms, 모바일: 40ms

## 7. 모션 안무

### 첫 화면

1. 핵심 이미지 또는 대표 오브젝트가 0→1 opacity와 16px 상승으로 등장한다.
2. 80ms 뒤 제목이 등장한다.
3. 다시 80ms 뒤 설명과 CTA가 함께 등장한다.
4. 전체 시퀀스는 1.2초 이내에 끝나고 반복하지 않는다.

### 스크롤 섹션

- 화면에 약 25% 들어왔을 때 한 번만 재생한다.
- opacity와 transform만 사용한다.
- 동시에 보이는 항목이 많아도 전체 stagger는 360ms를 넘기지 않는다.

### 상호작용

- hover: `translateY(-2px)`, 그림자/테두리 미세 강화
- press: `translateY(0) scale(0.99)`
- 선택: 색상 전환 + 체크/인디케이터 이동
- 저장 완료: 아이콘 scale 0.96→1과 160ms 색상 변화. confetti는 사용하지 않는다.
- 패널 열기: 240ms, 12px 이하의 이동 + opacity
- 모달 닫기: 160ms, 진입보다 빠르게 종료
- 탭 인디케이터: 240ms 이내의 위치 이동. 패널 콘텐츠는 120ms opacity 전환만 사용
- 드래그/리사이즈/스크럽: transition 없음. 입력과 화면 피드백의 1:1 대응을 우선

## 8. 성능 및 접근성

- transform과 opacity를 우선하고 width, height, top, left 애니메이션은 피한다.
- 대형 blur와 여러 개의 동시 box-shadow 애니메이션을 사용하지 않는다.
- `prefers-reduced-motion: reduce`에서는 비필수 이동, parallax, 자동 스크롤을 제거한다.
- reduced-motion에서도 콘텐츠는 즉시 보이며 상태 변화는 색상/아이콘으로 확인 가능해야 한다.
- 키보드 포커스는 hover와 동등한 정보를 제공한다.
- 작은 텍스트의 명암 대비는 WCAG AA를 만족시킨다.

## 9. 품질 체크리스트

- [ ] 첫 화면 애니메이션이 한 번만 재생되는가
- [ ] 한 화면에서 서로 다른 easing을 3개 이상 섞지 않았는가
- [ ] hover로 레이아웃이 흔들리지 않는가
- [ ] 메뉴/모달 종료가 진입보다 빠른가
- [ ] 모바일에서 stagger와 이동 거리가 줄어드는가
- [ ] reduced-motion에서 모든 콘텐츠와 기능에 접근 가능한가
- [ ] 4배 CPU slowdown에서도 스크롤 중 눈에 띄는 끊김이 없는가
- [ ] 애니메이션 종료 후 불필요한 `will-change`가 남지 않는가
